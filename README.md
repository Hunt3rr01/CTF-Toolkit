## 📌 About This Repository

Welcome to **Capture The Flag Toolkit & Resources** — a collection of useful tools, open-source projects, scripts, documentation, and online services related to offensive security.

This repository aims to provide a practical reference for security professionals and CTF players in areas such as:

- 🔎 Open Source Intelligence (OSINT)
- 🌐 Network Reconnaissance & Enumeration
- 🛡️ Vulnerability Assessment
- 💻 Web Application Security
- ⚔️ Penetration Testing & Red Team Operations
- 🧬 Digital Forensics & Malware Analysis
- 🎭 Social Engineering Awareness
- 📚 Security Documentation & Cheat Sheets
